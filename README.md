# Syncode Test Logs and Supplementary Data

This repository contains the complete raw logs and test data used in the evaluation of Syncode: A Visual Studio Code Extension for Real-Time Collaborative Programming Through the Integration of Conflict-Free Replicated Data Types (CRDTs) and Role-Based Access Control (RBAC).

## Contents

- crdt-benchmark - contains the raw logs and benchmark results for the CRDT evaluation.
- rbac-unit-testing and rbac-integration-testing - contains the raw test cases and results for the role-based access control unit and integration testing.

These files serve as supplementary materials for the manuscript appendices.
